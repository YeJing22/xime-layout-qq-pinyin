# QQ拼音版布局（曦码输入法）

一比一复刻 QQ 拼音九宫格、英文、数字键盘布局，**仅改动了九键、英文 26 键、数字键盘**三处，并且仅对九键编写快捷手势优化。切换中文26键全键盘可能会出现切换语言键、数字键盘键反复调换位置等不良体验，如果还需要使用全键盘的不建议应用此布局。

## 布局特点

### 中文九键（schemas里单独声明绑定了wanxiang_t9i，避免出现万象九键元书方案默认使用全键盘布局）

- 切换语言键（earth）在左，数字键在右
- **九宫格手势绑定个人高频使用快捷动作**：
  | 键 | 下滑 |
  | --- | --- |
  | 1 | 复制 |
  | 2 | 换行 |
  | 3 | 剪切 |
  | 4 | 全选 |
  | 5 | 左移1字符、右移1字符、行首、行尾 |
  | 6 | 粘贴 |
  | 7 | send_rime点击逗号 |  （如果使用万象拼音方案的超级提示super_tips功能，可以使用这个手势直接上屏提示里的emoji表情等）
  | 8 | send_rime点击冒号 |
  | 9 | send_rime点击句号 |

### 英文 26 键

- 切换语言键（earth）在左，数字键在右
- 英文逗号、英文句号分开在空格两边
- 符号键直接进入符号面板
- 123键直接进入数字键盘

### 数字键盘

- 返回按钮与中英文键盘123键位置保持一致
- 空格、点号键等布局修改为与QQ拼音完全一致
