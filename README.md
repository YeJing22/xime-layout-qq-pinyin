# QQ拼音版布局（曦码输入法）

一套按 QQ 拼音手感调过的曦码（Xime）键盘布局，**只动了九键、英文 26 键、数字键盘**三处，
其余保持官方默认。日常主力使用了很久，键位、上滑符号和编辑快捷键都是按高频动作摆的。

> 适配版本：曦码 3.0 及以上（`app_version: ">=3.0.0"`）

## 这套布局改了什么

### 九键（T9）

- 左栏只留 `候选` + `符号`，右栏 `退格` / `清空` / `回车`，中间 3×4 数字区 + `中英` `空格` `数字`
- **数字键下滑直达编辑动作**，不用进候选栏翻菜单：
  | 键 | 下滑 |
  | --- | --- |
  | 1 | 复制 |
  | 2 | 换行 |
  | 3 | 剪切 |
  | 4 | 全选 |
  | 5 | 行尾 |
  | 6 | 粘贴 |
- **5 键四向滑动移光标**：上滑行首、下滑行尾、左右滑逐字移动
- 7 / 8 / 9 上滑直接出 `，` `：` `。`（中文标点高频，省一次切换）

### 英文 26 键

- **q–p 上滑数字 1–0**，一排解决数字输入，不必切到数字键盘
- **a–l 上滑标点**：`~ / : ; “ ” - ( )`
- **z–m 上滑符号**：`* @ 、 ? ! % #`
- 长按出带音标的字母（`é è ê ë` 等），方便打人名和外语
- 退格：上滑清空、下滑撤回清空、左右滑清空当前编码
- `,` `.` 收窄到 0.5 宽，`shift`/`空格`/`Enter` 加宽，误触明显减少

### 数字键盘

- 左栏 `+ - * /` 与空格键，右侧竖排 `退格` `.` `表情` `回车`
- 4 行三列排布，底部 `符号` `0` `退格`，与九键的视觉节奏对齐

## 安装

**方式一：扩展商店（推荐）**
曦码输入法 → 设置 → 扩展商店 → 布局 → 搜索「QQ拼音版布局」→ 应用。

**方式二：手动**
把 `xime.custom.yaml` 放到手机 `files/rime/` 下（即 `xime.custom.yaml` 的常规位置），
重启输入法或重新部署一次。

## 已知情况

- 九键段额外声明了 `schemas: [wanxiang_t9i]`，用于让万象元书方案也用这套九键。
  没装该方案的用户不受影响——官方内置的其他 T9 方案绑定依然生效。
- 本布局不含配色与字体，只改键位与手势，套用后你原有的主题保持不变。
